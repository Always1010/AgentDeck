# 给内容生成 Agent 的输出约定

先从网页的“复制输出路径说明”取得当前项目实际挂载路径，再在用户授权范围内输出内容。项目名称不意味着跨电脑文件自动同步。

1. 阅读内容优先 HTML，Markdown 为补充；直接写到指定的真实项目目录。
2. 单文件和多文件 HTML 均可，多文件保留目录关系，使用相对 CSS/JS/图片/字体/JSON/CSV 地址。
3. 原生工具直接输出静态文件；构建工具在自己的源码目录独立构建，将整个输出目录挂载或保留在工具集合内。
4. 平台不安装工具依赖、不读取脚本后自动执行命令；不能只交付源码却声称工具可用。
5. 新内容无需改工作台源码、首页清单或路由，不要求附带 manifest。
6. 来源链接写进 HTML/Markdown 正文；HTML 外链采用新标签及 `noopener noreferrer`。
7. 纯前端工具优先相对资源和 hash 路由，不依赖 SSR、开发代理或 Node 后端。
8. 本地资源优先；依赖 CDN/API 的内容必须说明联网需求，不写入密钥。
9. 新页面先写资源再写入口。更新构建时避免过早删除旧哈希资源；V1 不提供原子发布。
10. 完成后报告真实文件位置、HTML 入口、构建命令和实际验证结果。模板仅是可选示例。
