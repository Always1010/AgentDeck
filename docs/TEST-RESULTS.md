## 千文件性能

样本为 3 个独立挂载、合计 1000 个小型 HTML 文件；在已运行正式服务中逐一登记。计时含 API 往返、扫描和网页更新，不是纯函数基准。

| 实测轮次 | 三挂载登记至索引完成 | 单文件写入至网页列表可见 |
| --- | --- | --- |
| 优化前 | 10660 ms | 2715 ms |
| 优化后独立回归 | 3464 ms | 1152 ms |
| 完整验收中的一轮 | 4253 ms | 1043 ms |
| 最终 7 项统一验收 | 4207 ms | 1116 ms |

单文件更新时间包含稳定写入等待、事件合并、索引更新与浏览器渲染，已在本机样本达到约 2 秒目标。不是多轮统计/P95，也不保证所有硬盘、目录规模和网络盘时延。最终完整测试可能打印略有波动的新测量，原始 JSON 保留该值。

## 失败及修复

实际测试暴露的项目问题已逐条记录并单独提交：预览 HEAD 检查 CSP、刷新开关回弹、敏感根校验、HEAD 正文、测试依赖漏洞、千文件更新延迟、端口冲突残留监听、Windows 排除项大小写、PATCH 默认值重置工具设置。详见 ISSUES.md。

另有两项测试本身调整：下拉框 accessible name 包含选项，改用匹配其真实名称；CORS 拒绝不保证浏览器发出可观察 response 事件，改验证真实请求失败并配合服务层 403 断言。Windows 正在监听的临时根直接重命名曾发生 EPERM；重新定位测试改为切换到另一已存在目录。没有声称 Windows 任意在线目录重命名已验证。

- 高级数据分析、模型调用、脚本/构建自动执行、云部署、远程/UNC、多用户、逐项目来源隔离、history fallback、原生系统文件夹弹窗、自动工具状态保存、原子多文件发布，均属明确后置/不做范围。

## 未验证 / 不保证

- macOS/Linux 运行和权限语义；Firefox/Safari、移动端视觉与完整键盘/屏幕阅读器审核。
- 真实 ACL 拒绝访问、实际物理磁盘拔插、系统断电后的配置持久性、多进程同时写同一个状态目录；不要运行这种共享状态配置。
- UNC/网络盘、超过 1000 文件的大规模/长时间压力、极长 Windows 路径和所有 Unicode/文件系统别名组合。
- 任意第三方 HTML 的内部功能、CDN/API 可用性、所有字体/媒体格式、未调整的根绝对资源或 history 路由。
- 未对所有链接/布局进行跨浏览器逐像素验证；未以 iframe load 或入口 200 宣称页面内部全部正确。
- 未验证不同项目之间机密隔离；V1 明确不提供这种隔离。
