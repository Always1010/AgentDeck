# AgentDeck 当前验证记录

更新日期：2026-09-30。本文只记录当前版本的完整验证结论、关键样本和已知限制。已经被后续实现替代的分阶段测试日志由 Git 历史保存，不在现行文档中持续累加。

## 最终结果

- TypeScript 全局检查、服务端编译及 Vite 正式构建通过。
- Vitest 全量：28 个文件、151 项通过。
- Windows Edge / Playwright 全量：102 项通过，用时约 4.9 分钟。
- 本机后台使用最终构建重新启动，4310 工作台与 4311 预览服务可用；新增批量状态接口实测正常，项目登记和挂载内容保留。
- 构建仍报告主包体积及 Zod 注释提示，不影响构建成功；当前主包约 639 kB，gzip 约 202 kB。

## 覆盖范围

- 项目与挂载：新增、追加、改名、停用、移除、离线恢复、旧链接迁移、目录排除、符号链接和路径边界；所有挂载内容保持原地只读。
- 内容查看：HTML 相对资源、Markdown、文本、图片缩放、SVG 源码、CSV/JSON 保真及规模限制、下载兜底和恶意 Markdown 过滤。
- 阅读工作台：多标签、分屏、最大化、沉浸、文件历史、滚动恢复、快捷键、主题、窄屏布局和 HTML 工具输入保留。
- 查找与定位：快速打开、复用已有阅读区、完整路径复制、按需展开定位、指定目录搜索、分页、取消及挂载变化后的旧结果清理。
- 更新检测：未读水位、单文件确认、文本自动更新、HTML 手动更新、可选的同目录资源变化提示、隐藏列表暂停和恢复后补查。
- 长期使用：独立阅读现场、命名和固定、常用组合副本、占用保护、个人备份下载与导入、白名单校验及事务失败回滚。
- 运行边界：正式与开发模式、端口占用、服务重启、浏览器进程重启、持久浏览器 profile、主服务和预览服务隔离。

第一轮完整回归发现并修复了 AD-030（程序滚动错误提升现场活跃时间）和 AD-031（新增顶部入口挤出窄屏帮助按钮）。修复后保留原有断言，先执行关联回归，再完成上述全量验证；没有通过放宽断言掩盖问题。

## 本机规模样本

| 样本 | 结果 | 测量边界 |
| --- | --- | --- |
| 恢复 24 个 HTML 标签 | 初始只创建当前页的 1 个 iframe；首次访问另一页后为 2 个，返回时输入保留 | 验证启动数量和实例保活，不代表长时间内存上限 |
| 连续 60 帧滚动后隐藏页面 | 最终全量中产生 1 次现场写入，刷新后恢复最新位置；独立回归曾测得 1–2 次 | 合并次数受实际帧时长影响，不承诺始终恰为 1 次 |
| 3 个挂载、1000 个文件 | 登记约 182 ms；首次展开含 334 个文件的目录约 594 ms | 本机单次样本，不作为跨机器性能承诺 |
| 收藏或工具列表隐藏 | 超过一个 4 秒周期没有状态请求；恢复后立即核对，快速隐藏并显示也会补查 | 只暂停平台检查，已加载 HTML 自身脚本仍可能运行 |
| 单文件更新 | 对应记录直接处理；无变化不序列化落盘；重复核对合并 | 通过访问计数、队列和落盘行为测试，不等同于完整 CPU 基准 |

## 执行入口

```powershell
npm run typecheck
npm test
npm run build
npm run test:e2e
```

浏览器测试使用隔离状态和临时目录，不读写用户的 AgentDeck 配置。Windows 默认使用本机 Edge；其他系统可通过 `PLAYWRIGHT_CHANNEL` 选择已安装浏览器。后台安装和恢复的专项验证见 [后台运行说明](BACKGROUND.md)。

## 当前未验证或不保证

- 未完成 macOS/Linux、Firefox/Safari、真实移动设备、完整屏幕阅读器和所有物理输入法组合的全量验证。
- 未进行超过 1000 文件的长时间压力测试、真实网络盘/UNC、物理磁盘拔插、系统断电恢复或多个服务共享同一状态目录的测试。
- 不保证任意第三方 HTML 的内部功能、CDN/API 可用性、所有字体和媒体格式、根绝对资源或 history 路由无需调整即可运行。
- 所有项目共用预览来源，不提供不互信项目或多用户之间的机密隔离。
- 个人备份不包含挂载源文件和网页工具临时输入；同目录资源提示不解析实际依赖，也不覆盖子目录。
- PDF、Office、全文检索、智能重命名追踪、脚本构建执行和原子多文件发布不属于当前能力。
