# AgentDeck 定位与体验优化方案

日期：2026-09-22。依据：原始 V1.1 规格、当前 README 和现有前后端实现。本文是产品建议，除明确标注的本次范围外，均未实施。

## 初衷与当前价值

AgentDeck 是 Agent 成果的本地使用入口：按项目挂载已有目录，直接阅读 HTML、Markdown 和原文，运行纯前端工具，发现变化后继续验收。Agent 负责生成和修改文件，用户负责判断成果是否满足需求，工作台负责把成果展示出来。三者形成“提出任务 → 文件落地 → 阅读 / 试用 → 反馈修改 → 收藏复用”的循环。

原规格强调项目、原地挂载、相对资源、只读源文件和大面积预览。当前实现进一步采用按需展开的真实文件树，保留阅读与工具输入状态，并提供独立于收藏的工具入口。原规格中的递归发现和自动工具发现已被后续设计替代，不能据此判定当前版本缺失功能。

值得保留的方向：不要求搬文件、不要求每份成果附带元数据、不替用户执行挂载目录中的脚本、不把生成内容塞进平台源码。产品价值在于降低“成果生成以后”的使用成本。

## 优化顺序

| 顺序 | 建议与用户收益 | 具体方案 | 验收标准 | 工作量估计 |
| --- | --- | --- | --- | --- |
| P0 · 本次 | 使用帮助：用户知道如何开始、怎样向 Agent 提需求 | 顶部和空状态提供入口；介绍上手、日常流程、沟通、输出要求、排错；提供报告、工具、修改、交接模板，可选真实挂载目录后复制 | 无项目也能看帮助；模板不编造真实路径；复制失败可手动复制；关闭帮助保留预览输入、滚动和焦点；窄屏可读 | 小到中 |
| P1 · 后续 | 当前成果的上下文交接：减少来回解释“哪个文件” | 在预览更多菜单增加“复制给 Agent”，组合项目、挂载根目录、相对路径、入口类型、用户填写的现象及验收标准；先预览再复制 | 不把平台 URL 当作跨电脑可访问地址；绝对路径清晰；不自动发送或附带文件正文 | 小 |
| P1 · 后续 | 最近访问：跨项目快速继续工作 | 浏览器本地保存有限条数的访问记录，沿用挂载 ID + 相对路径；提供清空入口；失效文件展示原因 | 无递归扫描；重启后可打开；不和收藏、工具分类互相覆盖 | 小 |
| P1 · 后续 | 预览排错：空白页时知道下一步 | 将现有错误细化为路径失效、挂载停用、目录离线、文件类型不支持；提供刷新、查看路径、打开帮助的对应入口；资源问题给出检查步骤 | 每种提示有真实依据；无法从跨来源页面获知的异常明确说明；不声称已检测所有资源错误 | 中 |
| P2 · 后续 | 内容交付约定复用：减少每次解释格式 | 帮助模板成熟后，提供可复制的项目说明片段；由用户放入内容目录的 AGENTS.md 或其他 Agent 指令文件 | 与原有规则合并；无自动覆盖；对不识别 AGENTS.md 的 Agent 提供显式提示 | 小 |
| P2 · 后续 | 阅读增强：让数据附件更方便核对 | CSV 有界只读表格、JSON 格式化与折叠、常见图片预览；保留原文 / 下载；限制大小和行数 | CSV 正确处理引号与换行；JSON 不损失大整数；超限有明确兜底；不执行数据内容 | 中 |

工作量是相对估计，不是排期承诺。建议先观察两类反馈：用户能否独立完成第一次挂载和交付；反馈修改时是否仍经常漏掉文件位置、现象或验收标准。无需为此默认收集使用数据。

## 本次帮助页面设计

- 保留现有快捷键弹窗，新增明确的“使用帮助”文字入口，避免让用户猜问号的含义。
- 帮助以整页阅读面板呈现，复用现有弹窗焦点管理与 Esc 行为；底层预览保持挂载。
- 按任务组织内容：快速上手、高效使用、与 Agent 沟通、任务模板、常见问题。
- 模板使用已登记且启用的目录；无目录时显示明确的待填写项。迭代和交接模板可引用当前文件，切换目录时不沿用其他目录的文件。
- 明确操作发生的位置：在 Agent 中生成 / 修改，在 AgentDeck 中挂载 / 阅读 / 检查；挂载不会把目录权限或页面状态自动交给 Agent。
- 不增加模型账号、自动执行命令或内嵌聊天。帮助内容、任务模板和布局本地可用，官方参考链接按需打开。

沟通方法参考 [OpenAI 官方最佳实践](https://learn.chatgpt.com/guides/best-practices)：明确目标、上下文、约束和完成标准；复杂任务先澄清方案；把稳定规则写进 AGENTS.md。页面中的 AgentDeck 工作流与模板结合本项目的实际能力编写。

## 实施与验证

由单个 Agent 完成即可：先提交定位与方案，再实现帮助页面、文档入口和相应浏览器检查，作为独立功能提交。此处属于新需求和体验优化，不自动创建问题日志。

验证重点是工作流而非静态文案快照：空工作台入口、真实路径模板、复制成功与失败兜底、键盘焦点、移动布局、打开 / 关闭帮助不重载当前 HTML。运行类型检查、构建以及相关快捷键与浏览器测试。
