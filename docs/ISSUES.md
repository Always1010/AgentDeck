# 已确认问题记录

## AD-001 — 预览响应检查被主平台 CSP 拦截

- 日期：2026-09-21
- 状态：已解决
- 现象：M2 加入入口 HEAD 检查后，正式模式浏览器无法打开 HTML，工具输入定位超时。
- 原因：主平台 `connect-src` 仅允许自身，未允许向独立预览来源检查响应；iframe 嵌入许可不等于 fetch 许可。
- 解决方案：仅将确定的预览来源加入主平台 `connect-src`；预览服务只向主平台返回 CORS 许可，管理接口仍拒绝预览来源。
- 验证：正式模式 Playwright 测试操作原生及构建工具，并检查隔离访问；实际运行结果见 TEST-RESULTS.md。
- 相关文件：`app/server/server.ts`、`app/web/Viewer.tsx`、`tests/e2e/workbench.spec.ts`。

## AD-002 — 刷新偏好开关在请求完成前回弹

- 日期：2026-09-21
- 状态：已解决
- 现象：取消自动更新时，受控复选框要等磁盘配置保存和重扫后才改变，浏览器操作检测到开关回弹。
- 原因：控件状态仅在异步请求结束后设置。
- 解决方案：立即更新当前偏好，保存失败回滚并显示错误；成功后以服务端状态对账。
- 验证：正式模式切换报告到提示模式，修改文件后页面不自动刷新。
- 相关文件：`app/web/Viewer.tsx`、`tests/e2e/workbench.spec.ts`。

## AD-003 — 敏感目录作为挂载根时绕过相对文件过滤

- 日期：2026-09-21
- 状态：已解决
- 现象：安全测试确认可以直接登记 `.git` 目录，此时内部普通 TXT 不再带有 `.git` 相对前缀；平台状态的祖先目录也可被登记。
- 原因：敏感名判断只用于挂载内部相对路径；挂载根校验没有覆盖其路径段与状态目录祖先关系。
- 解决方案：登记和每次读取时都检查真实根路径段；同时拒绝平台状态目录本身、子目录与祖先目录，防止状态写入落在发布根内。
- 验证：Windows 下敏感根、大小写、junction、编码越界和排除项测试。
- 相关文件：`app/server/path-policy.ts`、`tests/security.test.ts`。


## AD-004 — 显式 HEAD 路由仍创建正文流

- 日期：2026-09-21
- 状态：已解决
- 现象：注入式 HTTP 测试发现显式 HEAD 路由返回 HTML 正文。
- 原因：GET/HEAD 共用处理器未在响应头完成后提前结束 HEAD。
- 解决方案：HEAD 只返回校验后的状态及长度/MIME，不打开正文流。
- 验证：HEAD 正文为空、状态与 Content-Length 正确；正式模式浏览器预览响应检查通过。
- 相关文件：`app/server/server.ts`、`tests/security.test.ts`。
